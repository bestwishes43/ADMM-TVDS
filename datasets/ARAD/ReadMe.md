The hyperspectral Images of ARAD_1K dataset can be downloaded from [this link](https://codalab.lisn.upsaclay.fr/competitions/721#participate-get-data).

The RGB images in the ARAD_1K dataset are generated by adding Poisson noise to ideal spectral projections followed by JPEG compression. This approach lacks realistic imaging characteristics (Bayer mosaic sampling and additive sensor noise) while introducing non-physical JPEG artifacts that don't exist in actual camera measurements, making them unsuitable for imaging system simulation.

To create more realistic data, we generate noisy, demosaiced RGB images using a proper imaging pipeline. The coded aperture mask used in our simulation is the real measured mask obtained from [TSA-Net](https://github.com/mengziyi64/TSA-Net.git).
