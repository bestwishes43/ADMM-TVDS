The processed CAVE dataset can be downloaded from [Casformer](https://github.com/danfenghong/Information_Fusion_CasFormer/tree/main).

This dataset applies max-min normalization to the spectral images from [CAVE-28](https://github.com/TaoHuang95/DGSMP.git) and uses RGB images from the original [CAVE dataset](https://cave.cs.columbia.edu/repository/Multispectral).
